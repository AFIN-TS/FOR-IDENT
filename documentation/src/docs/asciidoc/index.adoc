== Overview
This documents contains a getting started guide and overview for the FOR-IDENT platform, the
successor of the ground breaking database STOFF-IDENT.

=== Technologies
Currently FOR-IDENT is build upon the following technologies:

* Java 8
* Spring 4
* Spring Boot
* Vaadin 7
* Gradle
* Git
* JPA (EclipseLink)
* Asciidoctor


=== Server
Host-specific details (hosting provider, VM sizing, IP addresses, network rules, user accounts and
credentials) are not stored in this repository. They are maintained by the operating organisation.

==== Installlation Details

===== Java
Install a Java runtime matching the version required by the build (see README).

===== Postgresql:

Connect as the "postgres" user
su - postgres
psql

Add a new user (as user postgres)
createuser --interactive

Add a database
createdb fi-production

==== Open Port for PSQL
Allow access to port 5432 only from the application server or an internal management subnet,
for example with iptables:
iptables -A INPUT -p tcp -s <MANAGEMENT_SUBNET> -d <DB_SERVER_IP> --dport 5432 -m tcp -j ACCEPT

Accept connection in PSQL
/etc/postgresql/<VERSION>/main/postgresql.conf
....
listen_addresses = '<DB_SERVER_IP>'
....

Accept connection type (restrict to the application server address)
/etc/postgresql/<VERSION>/main/pg_hba.conf
....
host    all             all             <APP_SERVER_IP>/32               md5
....

Database connections and the mail server are configured through environment variables
(see README, section "Configuration").

java -javaagent:spring-instrument-<VERSION>.jar
-jar de.hswt.fi.application-XXX.jar
--spring.profiles.active=production
--server.port=8080 > /dev/null 2>&1 &
