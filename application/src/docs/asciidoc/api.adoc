== Overview
The REST API gives read-only access to the substances of the public databases (STOFF-IDENT, PLANT-IDENT,
...). It needs no login.

The complete, always current description is generated from the code (since version 3.0):

* *Swagger UI* (try the requests in the browser): `/api/docs`
* *OpenAPI document* (JSON, for client generators): `/api/openapi`

This page summarises the endpoints. If you have suggestions or problems, please contact the operator of the site.

== General
The API is available over HTTPS only. All content is served as JSON (UTF-8). Empty values are returned as `null`,
not omitted.

== Pagination
The list endpoints are paged *per database*: `page` (0-based) and `size` (default 100) apply to each database, and the
pages of all databases are combined in one response. Its `content` can therefore hold up to `size` items per
database; `size` of the combined response is 0.

== Errors
Errors are answered without a body:

[cols="1,5"]
|===
|Status |Reason

|400
|A mass range wider than 200 Da, more than 100 IDs, or an invalid parameter value

|401
|`GET /api/substances` without one of the search parameter sets (as in all earlier versions)

|404
|Unknown path
|===

== Endpoint Overview

.Overview of the available endpoints
[cols="1,5,5"]
|===
|Method |URL |Brief description

|GET
|/api/substances/inchiKeys
|InChI keys of all substances (paged)

|GET
|/api/substances/ids
|IDs of all substances, e.g. `SI…` (STOFF-IDENT), `PI…` (PLANT-IDENT) (paged)

|GET
|/api/substances/inchiKeysAndIds
|Pairs of InChI key and ID of all substances (paged)

|GET
|/api/substances?inchiKey=VEQOALNAAJBPNY-UHFFFAOYSA-N
|The substance with the given InChI key, one entry per database that contains it

|GET
|/api/substances?id=SI00000528&id=PI00000001
|Substances by ID; at most 100 IDs, IDs without a substance are left out (a list, not a page)

|GET
|/api/substances?elementalFormula=C11H12N2O
|Substances whose formula *contains* the given text (C11H12N2O also finds C11H12N2O2) (paged)

|GET
|/api/substances?accurateMassMin=188.09&accurateMassMax=188.10
|Substances in the monoisotopic mass range, at most 200 Da wide (paged)
|===

== Examples

=== List all InChI keys

----
$ curl 'https://for-ident.example.org/api/substances/inchiKeys?page=0&size=2'
----

----
{"content":["FDMFUZHCIRHGRG-UHFFFAOYSA-N","RXYPXQSKLGGKOL-UHFFFAOYSA-N","KDXKERNSBIXSRK-UHFFFAOYSA-N", ...],
 "pageable":"INSTANCE","size":0,"last":true,"totalElements":8,"totalPages":1,"number":0,
 "sort":{"empty":true,"unsorted":true,"sorted":false},"first":true,"numberOfElements":8,"empty":false}
----

Two keys per database; the four databases give 8 keys.

=== List all InChI keys with their IDs

----
$ curl 'https://for-ident.example.org/api/substances/inchiKeysAndIds?size=1'
----

----
{"content":[["FDMFUZHCIRHGRG-UHFFFAOYSA-N","SI00010279"],["KDXKERNSBIXSRK-UHFFFAOYSA-N","PI00001151"], ...], ...}
----

=== Substance by InChI key

----
$ curl 'https://for-ident.example.org/api/substances?inchiKey=VEQOALNAAJBPNY-UHFFFAOYSA-N'
----

----
{"content":[{"inchi":"InChI=1S/C11H12N2O/c1-9-8-11(14)13(12(9)2)10-6-4-3-5-7-10/h3-8H,1-2H3",
  "inchiKey":"VEQOALNAAJBPNY-UHFFFAOYSA-N","monoisotopicMass":"188.095","elementalFormula":"C11H12N2O",
  "identifer":"SI00000528","name":"phenazone","datasourceName":"STOFF-IDENT"}], ...}
----

The ID field is called `identifer` (sic) for compatibility with existing clients.

=== Substances by ID

----
$ curl 'https://for-ident.example.org/api/substances?id=SI00000528'
----

----
[{"inchi":"InChI=1S/C11H12N2O/...","inchiKey":"VEQOALNAAJBPNY-UHFFFAOYSA-N","monoisotopicMass":"188.095",
  "elementalFormula":"C11H12N2O","identifer":"SI00000528","name":"phenazone","datasourceName":"STOFF-IDENT"}]
----
